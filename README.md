# vyges-est

Parasitic estimation before detailed routing: the RC network of every net, built from its
placement or from its global route, in the form a static timer reads.

- **Global route** (`wire`): one node per routing point, a resistor per route segment with its
  capacitance split to both ends, and a resistor from each pin to the grid point it attaches to.
- **Placement**: in progress.
